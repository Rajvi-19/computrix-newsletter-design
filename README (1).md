# COMPUTRIX --- E-Newsletter Design

A visual design project for the **Computer Engineering Department, L. D.
College of Engineering**.

## 📖 About the Project

**COMPUTRIX** is a departmental e-newsletter designed to present
achievements, activities, innovations, events, and other updates from
the Computer Engineering Department in a clean and modern editorial
format.

The design focuses on:

-   Professional academic presentation
-   Clean and structured layouts
-   Modern geometric visual elements
-   Consistent typography and spacing
-   A formal yet contemporary visual identity

## 🎨 Design Tools

-   **Canva** --- Design and layout
-   **Graphic design principles** --- Typography, composition,
    hierarchy, spacing, and visual balance

## 🖼️ Cover Page

The cover uses a minimal editorial style with:

-   A neutral background
-   Strong title typography
-   Green geometric accents
-   Thin-line geometric elements
-   Layered image panels
-   Circular and curved visual elements
-   A structured academic layout

![COMPUTRIX E-Newsletter Cover](cover/computrix-cover.png)

## ✨ Design Approach

The design was created with the goal of maintaining a balance between
**professionalism and visual creativity**.

Rather than using excessive decorative elements, the layout uses
geometric shapes, subtle lines, spacing, and image composition to create
visual interest while keeping the newsletter suitable for an academic
department.
